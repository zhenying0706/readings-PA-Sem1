# PA Sem 1 — Public Management AI & Administrative Burden Readings

这是一个面向独立研究与课程学习的双语阅读库，共收录 **41 篇论文、8 个主题分类、41 份逐篇笔记和 8 份分类综述**。每篇笔记均基于本地全文和 Zotero 元数据整理，并统一回答：为什么做、本质动机、basic idea、方法设计、证据支撑、研究空白、贡献与未来方向。

This bilingual reading repository supports independent study on public-sector AI, administrative burden, bureaucratic work, accountability, and inequality. It contains **41 papers, 8 categories, 41 article notes, and 8 category syntheses**. Each note is grounded in the local full text and Zotero metadata.

## 建议学习路线 | Suggested reading route

1. **A**：先建立行政负担、红带、AI实施与善治的概念地图。
2. **B–E**：依次理解GenAI、实施能力、官僚工作变化和问责/合法性。
3. **F–G**：进入行政负担的机制、测量、第三方、腐败控制与分配后果。
4. **I**：用新加坡案例连接亚太地区的AI治理与制度情境。

Recommended sequence: **A → B/C/D/E → F/G → I**. Read the category synthesis first, then the article notes, and finally return to the synthesis to formulate cross-paper questions.

方法学习建议先读根目录的[研究方法与数据处理学习手册](METHODS_AND_DATA_GUIDE_CN.md)。手册按方法去重讲解，并用41篇覆盖表标注每种方法对应的论文、数据处理步骤、识别假设、系数解释、机制证据和结论边界。

理论学习建议配合[中文版理论与分析框架学习手册](THEORIES_AND_ANALYTICAL_FRAMEWORKS_GUIDE_CN.md)或[中英文对照版](THEORIES_AND_ANALYTICAL_FRAMEWORKS_GUIDE_BILINGUAL.md)。手册逐篇标出明确采用的理论、作者自建框架、核心因果逻辑、实际检验方式和证据等级，并按相同理论去重讲解如何形成构念、机制、边界条件和研究假设。

导师汇报可直接按[中文文献综述](ADVISOR_LITERATURE_REVIEW_CN.md)或[中英文对照文献综述](ADVISOR_LITERATURE_REVIEW_BILINGUAL.md)、[总思维导图与框架](ADVISOR_VISUAL_FRAMEWORKS.md)，再选择[中文汇报提纲](ADVISOR_MEETING_BRIEF_CN.md)或[中英文对照汇报提纲](ADVISOR_MEETING_BRIEF_BILINGUAL.md)。综述以“制度环境—组织实施—裁量配置—国家公民界面—行政负担—公共价值结果”为整合主线，不是对41篇论文的逐篇重复。

质性方法学习建议配合[质性研究方法教学手册](QUALITATIVE_METHODS_GUIDE_CN.md)。该手册面向零基础学生，系统讲解文献综述体系（叙述性综述/系统综述/Meta分析/质性元综合的区别）、案例研究法（Yin方法论）、三大质性编码流派（内容分析、扎根理论、主题分析）、访谈与实地方法、理论框架如何操作化为编码工具，以及质性研究的严谨性标准，并附有中英术语表。

## 如何使用每篇笔记 | How to use each note

每篇笔记都区分论文实际做出的证据与可供后续研究的推论。概念论文和综述不会被写成实验；相关性、准实验和随机实验也不会被混为一谈。建议阅读原文时重点核对研究对象、样本、识别策略、测量、机制与外部效度。

Each note separates demonstrated evidence from inference and future possibilities. Conceptual pieces and reviews are not described as experiments, and correlational, quasi-experimental, and randomized evidence are kept distinct.
